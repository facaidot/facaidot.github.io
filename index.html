METHODOLOGY

十五五主线战法

五层漏斗筛选体系——从宏观到微观，层层过滤，锁定高确定性标的

LAYER 01
政策方向定调
深度解读十五五规划及配套政策，明确国家战略重点方向，锁定政策红利赛道。从顶层设计出发，确定半导体、AI、新能源等核心主线。
▼
LAYER 02
产业趋势研判
分析产业链上下游供需格局、技术路线演进、竞争壁垒变化，判断产业发展阶段（导入期/成长期/成熟期），寻找处于加速拐点的细分领域。
▼
LAYER 03
资金流向验证
通过日度板块热度追踪、主力资金流向分析、北向资金动向监测，验证市场对产业趋势的认可度。只有资金确认的方向，才具备可操作性。
▼
LAYER 04
个股基本面筛选
在确认方向后，通过公告穿透法、财务指标交叉验证，筛选出具备核心竞争力和业绩兑现能力的优质标的，排除概念炒作和财务造假。
▼
LAYER 05
技术面择时入场
结合量价关系、支撑阻力位、资金进出节奏，在关键位置等待确认信号后入场。严格执行止损纪律，控制回撤，保护本金安全。
OUTPUT
高确定性 · 低风险偏好 · 纪律化执行

日度板块热度追踪
日更
OVERVIEW
每日追踪14只关注标的所属板块的资金流向、历史位置安全度、个股性价比，从政策-产业-资金三维评估板块热度，结论有判断不模棱两可。
ANALYSIS DIMENSIONS
  • 政策支持力度：评估板块对应政策红利的持续性与加码空间
  • 产业发展阶段：判断板块处于导入期、成长期还是成熟期
  • 资金流入流出：追踪主力资金、北向资金动向，验证市场认可度
  • 历史位置安全度：计算板块当前价格相对历史高低的百分比，数值越低安全度越高
  • 个股性价比：结合估值水平与成长性匹配度测算，优先选择低估且成长明确的标的
💡 核心特色
不做模糊判断，每个板块明确给出"持有 / 追入 / 观望 / 回避"的操作建议，结合热度、安全度、资金流向综合决策。

公告穿透法
日更
OVERVIEW
协议转让深度分析，穿透受让方背景、产业协同、解禁影响，从投资者视角判断实质性影响，而非停留在公告表面信息。
ANALYSIS FRAMEWORK
  • 受让方背景穿透：挖掘协议受让方实际控制人、关联产业与历史投资轨迹
  • 产业协同分析：判断受让方与标的公司的业务互补性与战略协同价值
  • 解禁影响评估：计算未来解禁规模与节奏，评估对股价的潜在冲击
  • 实质性影响判断：从投资者视角区分"利好信号"与"实质性利好"
💡 核心特色
不满足于公告字面信息，逐层穿透到真实意图。每份公告分析都给出明确的投资影响判断：利好/中性/利空，以及是否值得跟进。
